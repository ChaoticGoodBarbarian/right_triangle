Right Triangle
Time limit: 1 second
Memory limit: 64.0 MB

Input
Standard input or input.txt

Output
Standard output or output.txt

Write a program that checks whether a triangle is right-angled.

Input format
Three positive integers are given — the sides of the triangle.
All numbers do not exceed 30000.

Output format
If the given triangle is right-angled, print YES.
If the triangle is not right-angled, print NO.
If a triangle with such sides cannot exist, print UNDEFINED.

Example 1
Input
3
4
10
Output
UNDEFINED

Example 2
Input
3
4
5
Output
YES
